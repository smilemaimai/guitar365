# Guitar 365

365 天的木吉他課程 Web App。用電腦或手機的麥克風收音，即時判斷你彈的**單音、和弦刷奏**和**節奏**。

- **365 課，分 12 個階段**：空弦與單音 → 第一批開放和弦 → C、G、Dm 與基本刷法 → 七和弦與藍調 → 指彈入門 → F 與封閉和弦 → 大調音階與旋律 → 十六分刷法與切分 → 小調、五聲與獨奏 → 色彩和弦 → 指彈進階 → 綜合曲風與彈唱伴奏。每 7 天一次複習，第 365 天是畢業演出。
- **每課兩顆星**
  - ① 彈對：不限時間，彈對才會前進。正確率 ≥ 80% 得 ★
  - ② 彈對＋節奏：拿到第一顆星後解鎖。跟著節拍器彈，命中率 ≥ 80% 且速度達到目標 BPM 得 ★，並標示 **COMPLETE**
- **聽得懂和弦**：刷和弦時用頻譜的 12 音級能量比對目標和弦；單音用 YIN 音高偵測；起音（撥弦、刷弦的瞬間）用頻譜通量偵測，連續刷弦也分得開
- 其他功能：六線譜、和弦指法圖、撥弦合成示範、節拍器（4/4、3/4、6/8）、調音器、延遲校正、進度匯出／匯入
- 曲目都是傳統民謠或公有領域的古典曲（小星星、歡樂頌、綠袖子、愛的羅曼史、卡農進行……）
- 純前端，不需要伺服器或帳號。進度存在瀏覽器的 localStorage 裡，聲音不會上傳

## 部署到 GitHub Pages

1. 在 GitHub 建立一個新的 repository（例如 `guitar365`）
2. 把這個資料夾推上去（見下方指令）
3. 到 repository 的 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save
4. 約一分鐘後網址會是 `https://<你的帳號>.github.io/guitar365/`

```bash
git remote add origin git@github.com:<你的帳號>/guitar365.git
```

```bash
git push -u origin main
```

> 麥克風只能在 HTTPS 或 localhost 下使用，GitHub Pages 預設就是 HTTPS。

## 本機執行

```bash
python3 -m http.server 8366
```

然後打開 http://localhost:8366

## 使用建議

- 把手機或筆電放在吉他正前方 30～50 公分、對著音孔。環境越安靜越準
- 先用「調音器」把六條弦調準——音不準，和弦就會被判錯
- 節奏模式建議戴耳機聽節拍器
- 第一次使用請到「設定」做一次**自動延遲校正**
- 和弦一直被判錯：先逐弦檢查有沒有悶掉的音；還是不行就到「設定 → 和弦判定」改成寬鬆
- 在手機上可以用瀏覽器的「加入主畫面」，像 App 一樣全螢幕開啟
- 電腦和手機的進度不會自動同步，請用「設定 → 匯出／匯入進度」

## 檔案結構

| 檔案 | 內容 |
|---|---|
| `js/lessons.js` | 課程產生器：12 個階段的課程、和弦指型、刷法與指彈型態、旋律庫，自動排六線譜指位 |
| `js/dsp.js` | 訊號處理：YIN 音高、FFT 與 12 音級能量、和弦比對、起音偵測、撥弦合成 |
| `js/audio.js` | 麥克風、示範音、節拍器 |
| `js/app.js` | 介面、練習判定、調音器、設定 |
| `css/style.css` | 樣式（支援手機） |
| `test/check.js` | 開發用：`node test/check.js` 檢查 365 課的資料，並用合成吉他聲驗證偵測演算法 |
| `test/sim.js` | 開發用：在瀏覽器裡用合成吉他聲代替麥克風，跑一次完整的練習流程 |

## 已知限制

- 上刷只刷到部分的弦，所以上刷的判定比下刷寬鬆（只要聲音落在目標和弦的組成音裡就算對）
- 悶音、切音、推弦、搥勾弦這些「技巧」聽不出來，App 只判斷音高（或和弦）與時間點
- 指彈分解和弦時前面的音還在響，單音的判定會比較寬鬆
